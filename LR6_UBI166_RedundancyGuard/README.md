# ЛР6 — индивидуальная часть
## Вариант 13 — УБИ.166 «Внедрение системной избыточности»

Выполнил студент группы КП-23-11 Тер-Саргсян Рубен Арманович.

Проект Redundancy Guard сравнивает фактический состав запущенных компонентов с эталонной конфигурацией и выявляет неразрешенные и устаревшие компоненты.

Запуск:
```bash
python3 main.py
```

Структура:
- main.py — запуск, сводка и CSV;
- redundancy_guard.py — основная логика;
- logger_utils.py — журналирование;
- config.json — эталонная и фактическая конфигурация;
- .replit — запуск в Replit;
- replit.nix — системное окружение;
- logs/ — лог;
- output/ — результаты;
- docs/ — текст для отчета и блок-схема.

Контрольный результат:
8 компонентов, 4 разрешенных, 4 избыточных, 50%.
